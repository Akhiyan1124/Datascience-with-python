# Lab 20: Build a Custom Data Cleaning Pipeline

## 📄 Overview
This lab demonstrates the creation of a **custom, reusable data cleaning pipeline** using Python and pandas. The pipeline addresses common data quality issues such as missing values, duplicates, inconsistent data types, outliers, and unstandardized text, and is designed to work across multiple datasets.

By the end of this lab, users will be able to:
- Apply standardized cleaning procedures to datasets.
- Handle missing values, duplicates, and outliers effectively.
- Create maintainable and modular preprocessing code.
- Validate and verify the cleaning results.
- Generate visualizations and reports to support analysis.

---

## 🧰 Prerequisites
Before starting this lab, you should have:
- Basic Python programming knowledge (variables, functions, loops)
- Familiarity with pandas and NumPy
- Understanding of CSV files and DataFrames
- Knowledge of data quality issues (missing values, duplicates, inconsistent data types)

---

## ⚙ Lab Environment
The lab was designed to run in:
- **Python 3.8+**
- **Jupyter Notebook**
- Libraries: `pandas`, `numpy`, `matplotlib`, `seaborn`
- Sample datasets: `hospital_data.csv`, `transport_data.csv`

---

## 📝 Key Tasks

1. **Understand Data Cleaning Pipeline Concepts**
   - Identify common data quality issues
   - Explore sample datasets

2. **Design Data Cleaning Functions**
   - Handle missing values
   - Remove duplicates
   - Fix data types
   - Handle outliers
   - Standardize text data

3. **Apply the Cleaning Pipeline**
   - Clean **Hospital** dataset
   - Clean **Transport** dataset

4. **Validate Cleaning Results**
   - Ensure no missing values in critical columns
   - Verify duplicate removal
   - Check data type consistency
   - Validate numeric ranges and overall data integrity

5. **Visualizations**
   - Missing values (before and after cleaning)
   - Duplicate record comparison
   - Numeric distribution and outliers
   - Transport delays and correlations

6. **Documentation & Reporting**
   - Generated detailed cleaning report
   - Created pipeline documentation
   - Generated final summary of results
