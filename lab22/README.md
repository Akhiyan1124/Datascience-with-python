# 📊 Titanic Data Analysis with Seaborn

This project demonstrates statistical data visualization using Seaborn on the Titanic dataset.

---

## 🚀 Objectives

- Visualize distributions using histograms
- Identify outliers with boxplots
- Analyze density using violin plots
- Perform grouped analysis using hue
- Build subplot grids using FacetGrid
- Generate insights from real-world data

---

## 🛠️ Technologies Used

- Python
- Seaborn
- Matplotlib
- Pandas
- NumPy

---

## 📊 Visualizations

- Histogram (Age Distribution)
- Boxplot (Age vs Class)
- Violin Plot (Age vs Gender)
- FacetGrid Analysis
- Dashboard (Multiple Plots)

---

## 📸 Sample Output

![Dashboard](images/dashboard.png)

---

## 🔍 Key Insights

- Females had a higher survival rate than males
- First-class passengers had better survival chances
- Fare is strongly linked with survival probability
- Age distribution shows most passengers were young adults
