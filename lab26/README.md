📊 Interactive Visuals with Bokeh
🚀 Overview

This project is an interactive Data Visualization Dashboard built using Python, Bokeh, Pandas, and NumPy.

The project demonstrates how to create powerful interactive visualizations with:

Interactive stock market charts
Weather dashboards
Hover tooltips
Filters and sliders
Color legends and themes
Standalone HTML dashboards

The project showcases how Bokeh can be used to build professional and web-ready interactive data visualizations.

Install the required Python libraries:

▶️ Running the Project

Run any visualization script:

python stock_chart.py

or

python weather_dashboard.py
