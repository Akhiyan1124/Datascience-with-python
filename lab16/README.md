# Lab 16: Handling Missing Values and Outliers

## Overview

In this lab we explore techniques used in real-world data science projects to clean datasets and improve data quality.

## Techniques Used

- Missing Value Detection
- Mean Imputation
- Median Imputation
- Outlier Detection using IQR
- Outlier Detection using Z-Score
- Outlier Treatment using Capping

## Libraries Used

- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
