# 📊 Interactive Data Visualization with Plotly (Lab 24)

## 🚀 Overview
This project demonstrates how to create **interactive data visualizations** using the Plotly library in Python.  
It covers line charts, bar charts, dynamic axes, and exporting dashboards as HTML for sharing.

Interactive visualizations allow users to explore data dynamically through hover effects, zooming, and filtering — making them more powerful than static charts.

---

## 🎯 Objectives
By completing this lab, I learned how to:

- Create interactive **line charts** using Plotly
- Build dynamic **bar charts** with hover functionality
- Customize **legends and layout**
- Implement **dynamic axes** (range selectors & sliders)
- Export visualizations as **interactive HTML dashboards**
- Understand the importance of interactive data storytelling
