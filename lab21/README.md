# 📊 Lab 21: Data Visualization with Matplotlib

This project demonstrates how to create professional data visualizations using Python and Matplotlib.

---

## 🚀 Objectives

- Create line plots
- Build bar charts (vertical, horizontal, grouped)
- Generate scatter plots
- Customize charts (colors, styles, annotations)
- Save plots in multiple formats
- Create dashboards using subplots

---

## 🛠️ Technologies Used

- Python
- Matplotlib
- NumPy

---

## 📊 Visualizations Included

- Line Plot (Temperature Trend)
- Bar Charts (Sales & Ratings)
- Scatter Plot (Study vs Score)
- Advanced Styled Charts
- Dashboard (Multiple Charts)
