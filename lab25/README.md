# 📊 COVID-19 Trend Dashboard with Plotly

## 🚀 Overview
This project is an interactive **COVID-19 Trend Dashboard** built using **Python, Plotly, Pandas, and Dash**.  

The dashboard provides visual insights into:
- Confirmed COVID-19 cases
- Death trends
- Recovery trends
- Daily new cases
- Country-wise comparisons

The project demonstrates how interactive data visualization can help analyze real-world datasets effectively.
