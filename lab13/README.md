# Lab 13: Filtering, Sorting, and Merging DataFrames

## Overview
This lab demonstrates how to manipulate and analyze datasets using the Pandas library in Python.

The project covers filtering, sorting, and merging DataFrames to perform real-world data analysis tasks.

---

## Objectives

- Filter DataFrame rows using conditions
- Sort values by single and multiple columns
- Merge CSV files using common columns
- Apply logical operators for filtering
- Understand DataFrame joins (inner, left, right, outer)

---

## Technologies Used

- Python
- Pandas
- NumPy

---

## Dataset

Two datasets are created in the code:

- hospitals.csv
- locations.csv

These datasets simulate hospital information and geographic locations.

---

## Key Operations Performed

### Filtering
- Single condition filtering
- Multiple condition filtering
- String based filtering

### Sorting
- Sorting by bed count
- Sorting by satisfaction
- Sorting by multiple columns

### Merging
- Inner Join
- Left Join
- Right Join
- Outer Join

---

## Final Analysis

The lab combines filtering, sorting, and merging to create a complete hospital data analysis pipeline and generate statistical summaries.
