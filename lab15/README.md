# Lab 15: Data Cleaning and Preprocessing

This project demonstrates data cleaning and preprocessing techniques using Python and Pandas.

## Objectives

- Understand the importance of data cleaning
- Rename columns to standard format
- Convert data types
- Handle missing values
- Remove unnecessary rows and columns
- Validate data quality

## Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Dataset

Walmart Sales Dataset containing store sales information.
