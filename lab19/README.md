# ✈️ Flight Delay Data Analysis Lab

## Overview

This project analyzes a flight delay dataset using Python and data analysis techniques. The goal of this lab is to explore flight delays and identify patterns using data manipulation and visualization.

## Objectives

- Load and examine flight delay data using Python
- Perform data cleaning and preprocessing
- Handle missing values
- Filter datasets for targeted analysis
- Group and analyze delays by different factors
- Visualize delay patterns using charts

## Dataset

The dataset contains flight-related information including:

- Month
- Day of Week
- Scheduled Departure
- Distance
- Arrival Delay
- Airline Indicators
- Airport Indicators

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed

The lab performs the following tasks:

1. Load and inspect the dataset
2. Handle missing values
3. Filter flights based on distance
4. Calculate average arrival delays
5. Group delays by month
6. Group delays by day of the week
7. Identify flights with the highest delays
8. Create delay categories
9. Visualize delay patterns

## Visualizations

The project includes the following charts:

- Average Delay by Month
- Delay by Day of Week
- Arrival Delay Distribution
- Distance vs Delay Scatter Plot
- Delay Category Distribution

## Key Insights

- Flight delays vary significantly across different months.
- Certain days of the week show higher average delays.
- Distance can influence arrival delays.
- Categorizing delays helps identify operational patterns.
